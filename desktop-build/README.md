# PerfoStudio Desktop — сборка .exe

В этой папке лежит offline-версия PerfoStudio (генератор перфорации из
изображения) на Python + tkinter, с тем же алгоритмом, что и в веб-версии,
плюс скрипт для автоматической сборки в .exe.

## Что нужно
- Windows
- Установленный Python 3.8+ (https://python.org) — при установке отметьте галочку "Add Python to PATH"

## Как собрать (просто)

1. Скачайте папку `desktop-build` целиком на свой компьютер.
2. Дважды кликните на файл **`СОБРАТЬ.bat`**.

Готовый файл появится в папке `dist/PerfoStudio.exe` (или `dist/App.exe`,
если запущено без параметров) — его можно копировать и запускать на любом
Windows-компьютере без установки Python.

Если `.bat` пишет "Python не найден" — установите Python с https://python.org
и при установке ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH", затем
запустите `.bat` заново.

## Возможности интерфейса
- Каждый параметр (шаг сетки, диаметры отверстий, чувствительность, порог,
  настройки G-code и т.д.) можно как двигать ползунком, так и напечатать
  вручную в поле рядом — значения синхронизированы в обе стороны.
- Диапазоны и шаги полей полностью соответствуют веб-версии сайта.
- Полный блок настроек G-code (подача, врезание, безопасная высота,
  глубина реза, диаметр фрезы, обороты шпинделя) — как на сайте.

## Файлы проекта
- `app.py` — интерфейс приложения (tkinter): загрузка изображения, настройки,
  предпросмотр, экспорт
- `perfo_core.py` — логика генерации перфорации (1:1 перенос алгоритма из
  веб-версии `src/lib/perfo.ts`): гистограммное выравнивание яркости,
  защита от наложения отверстий, экспорт в DXF/SVG/CSV/G-code
- `requirements.txt` — зависимости (Pillow для работы с изображениями)
- `build.py` — скрипт автосборки в .exe (PyInstaller)
- `СОБРАТЬ.bat` — запуск сборки одним кликом

## Свои параметры (через командную строку)

Откройте командную строку в этой папке и выполните:

```
python build.py app.py PerfoStudio
```
— соберёт `app.py` в файл `dist/PerfoStudio.exe`.

Если нужен собственный скрипт вместо `app.py`:
```
python build.py my_script.py MyAppName
```

Если программа консольная (использует `print`/`input` и нужно видеть окно терминала):

```
python build.py my_script.py MyAppName console
```

То же самое можно сделать через `.bat`, передав аргументы:
```
СОБРАТЬ.bat app.py PerfoStudio
```

## Примечания
- Первая сборка может занять 1-2 минуты — скрипт автоматически поставит
  PyInstaller и зависимости из `requirements.txt`.
- Файл получается "portable" (--onefile) — один .exe без установки.
- Антивирусы иногда ложно ругаются на файлы, собранные PyInstaller — это
  известная особенность, не связанная с вредоносным кодом.
