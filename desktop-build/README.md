# Сборка .exe из Python-скрипта

## Что нужно
- Windows
- Установленный Python 3.8+ (https://python.org) — при установке отметьте галочку "Add Python to PATH"

## Как собрать (просто)

1. Скачайте папку `desktop-build` целиком на свой компьютер.
2. Замените содержимое `app.py` на свою программу (или добавьте рядом свой `.py` файл).
3. Дважды кликните на файл **`СОБРАТЬ.bat`**.

Готовый файл появится в папке `dist/App.exe` — его можно копировать и запускать на любом Windows-компьютере без установки Python.

Если `.bat` пишет "Python не найден" — установите Python с https://python.org и при установке ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH", затем запустите `.bat` заново.

## Свои параметры (через командную строку)

Откройте командную строку в этой папке и выполните:

```
python build.py my_script.py MyAppName
```
— соберёт `my_script.py` в файл `dist/MyAppName.exe`.

Если программа консольная (использует `print`/`input` и нужно видеть окно терминала):

```
python build.py my_script.py MyAppName console
```

То же самое можно сделать через `.bat`, передав аргументы:
```
СОБРАТЬ.bat my_script.py MyAppName console
```

## Примечания
- Первая сборка может занять 1-2 минуты — скрипт автоматически поставит PyInstaller.
- Файл получается "portable" (--onefile) — один .exe без установки.
- Антивирусы иногда ложно ругаются на файлы, собранные PyInstaller — это известная особенность, не связанная с вредоносным кодом.
